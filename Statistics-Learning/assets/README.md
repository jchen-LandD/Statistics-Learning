# 資源文件夾

## 圖表圖片

請將以下圖片保存到此文件夾中：

### 1. boxplot.png
- 盒鬚圖示意圖
- 顯示 MIN, Q1, MEDIAN, Q3, MAX 及異常值
- 用於第1單元：盒鬚圖講解

### 2. histogram.png
- 直方圖示意圖
- 顯示數據頻率分佈
- 用於第1單元：直方圖講解

### 3. normal_distribution.png
- 常態分佈曲線圖
- 顯示 μ±1σ, μ±2σ, μ±3σ 的百分比
- 用於第2單元：常態分佈講解

## 使用方式

HTML 中會自動引用這些圖片，例如：
```html
<img src="assets/boxplot.png" alt="盒鬚圖" style="max-width: 100%; height: auto;">
```

## 圖片要求

- 格式：PNG 或 JPG
- 寬度：600-800px（用於網頁顯示）
- 清晰度：適合屏幕閱讀
